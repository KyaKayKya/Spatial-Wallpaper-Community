# 渲染与资源边界

作者工程固定使用 Unity **2022.3.62f3**、URP **14.0.12**、Linear、Windows x86-64／D3D11。渲染扩展以发行物声明的可信配置为准；虚拟屏幕菜单中的选项不等于该硬件配置已完成 RC 验收。

## 匹配制作预览配置

Starter Kit 在没有渲染管线的工程中创建固定 Forward+ 配置。已有 URP 资产不会被样例生成器替换。

要比较普通 Play 和沙箱的画面，将制作侧设置与发行物的 `contracts/render-profiles.json` 对齐：Forward+、HDR、MSAA 4、深度与不透明纹理开启，不添加 Renderer Feature。主灯光、附加逐像素灯光和软阴影开启，单级阴影级联、阴影距离 12；制作相机启用后处理。即使没有添加后处理效果，关闭该相机开关也可能产生少量颜色舍入差异。

先在工程副本上调整已有配置，再检查普通 Play 和沙箱预览。制作侧的自定义管线设置不会自动随场景快照进入客户端。

## 作者可以提交的内容

场景快照包含受检查的节点、数据、材质、网格、纹理、Prefab、受限程序和获准 Shader。`contentRoot` 外的引用会被拒绝；Prefab 通过专用 `Prefab` 字段指向资产，不以外部场景对象替代。

内置 Lit/Unlit 的属性表与参数限制见[作者 API](AuthorApi.md)。自定义 Shader 由固定 Unity 工具链构建，沿用同一个 Shader Bundle 格式验证器，在进入原生加载器之前接受检查。脚本材质当前接受受支持的 Color、Float/Range 和纹理属性；不接受任意关键字组合、非默认材质渲染状态或纹理偏移缩放。先用 Starter Kit 的 Shader 示例验证自己的修改。

动态网格、纹理、材质与 Prefab 使用受控 API，仍计入资源预算。当前示例中的动画由 `Update` 更新属性实现，不能据此推断 Animator、骨骼蒙皮或所有 Unity 组件可导出。

## 灯光

现代脚本场景支持启用的实时 Point、Spot 和 Directional 灯光，保存颜色、强度、范围、内外锥角、阴影类型、强度、Bias、Normal Bias 和 Near Plane。具体数值范围见[作者 API](AuthorApi.md)。固定 URP 自身的限制仍适用，例如 Point 阴影不使用 Normal Bias。

灯光上的 `UniversalAdditionalLightData` 仅作为可信管线配置读取。`Use Pipeline Settings` 开启时，阴影偏移由发行物的管线设置决定；关闭时使用灯光自身的偏移值。未附加该组件时按开启处理。阴影图集属于共享管线资源，在 Worker 开始渲染前计入预算。

Cookie、Flare、烘焙灯光、Area 灯光、自定义光照层及未覆盖的附加设置会在导出时被拒绝。保留默认附加设置后再预览。

## 背景、环境光和后处理

在 `contentRoot` 上添加一个 `ScenePresentationSettings`，设置自定义背景、平面或渐变环境光，以及 Bloom、ACES、曝光、饱和度和暗角。完整参数范围见[作者 API](AuthorApi.md)。该组件只能放在场景内容根节点，不能放入可实例化的 Prefab。

这组受控呈现设置不导出天空盒、反射探针或环境反射贴图。启用时关闭默认环境反射，避免 Worker 继承构建场景的天空反射；Lit 材质仍接受已导出的环境光和实时灯光。

勾选 **Apply In Play** 后，普通 Editor Play 使用这些受控参数；停止时恢复相机背景、清屏方式、环境光、环境反射强度和后处理开关。此选项默认关闭，供已有场景保留自己的呈现方式。沙箱和客户端使用已导出参数，不依赖这个预览开关。

此路径使用可信配置 `spatial.urp.forward-plus` **1.1.0**，固定引擎与 URP 版本不变。安装同一次候选发行的 SDK 和运行时；旧配置不会自动升级。主相机和剪裁深度不能通过此组件覆盖，深度由场景参考框定义。任意 Volume、VolumeProfile、Renderer Feature 和未声明的后处理组件仍不能随作者包导出。

## 可信平台扩展

主相机、离轴投影、渲染管线配置、Renderer Feature、平台 RenderPass、桌面挂接、设备输入与能力代理由可信平台拥有。作者包不能携带任意 C# Renderer Feature、原生插件或替换主投影。把可编辑的 Shader 资源与平台执行代码分开，不会限制作者用已获准的材质和数据制作画面。

新增平台渲染配置必须先证明固定引擎/URP 兼容、投影与资源所有权正确，再通过相应回归后进入发行配置。NPR 在兼容性及许可验证完成前不纳入正式支持；不要因本机 Editor 能显示就把 NPR 插件加入作者安装依赖。
